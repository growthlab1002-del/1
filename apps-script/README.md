# 주문 점검 대시보드

「마진계산 주문처리정리_2026년」 시트를 읽어서 문제 있는 주문만 골라 보여 주는 웹페이지입니다.
**시트는 읽기만 하고 절대 수정하지 않습니다.**

## 점검 항목

| 항목 | 이런 건이 잡혀요 |
|---|---|
| 해외 발주 누락 | 주문 후 2일이 지났는데 해외주문번호·결제날짜·송장이 모두 비어 있는 건 (체크 건은 제외) |
| 취소했는데 발송됨 | 상태가 취소·반품인데 송장이 있는 건, 또는 배대지(유프레이트·에코)나 발송정보일괄등록에는 있는데 주문 탭에서 행이 지워진 건 |
| 해외 자동취소 의심 | 발주했는데 7일이 지나도 송장이 안 생긴 건 → 구매처 사이트에서 확인 필요 |
| 배대지 수량 불일치 | 주문 수량과 유프레이트 송장시트 수량이 다른 건 |
| 원가 미입력 | 발주했는데 원가계가 비어 있는 건 |
| 체크(보류) 건 | 상태가 "체크"인 건(마진·재고 문제로 발주 보류). 3일 이상이면 주황, 5일 이상이면 빨강 |

- 각 건의 주문번호를 누르면 시트의 해당 행으로 바로 이동합니다.
- **확인함** 버튼을 누르면 그 건은 목록에서 숨겨집니다. 이 기록은 시트가 아니라 스크립트 저장소에 따로 저장됩니다.
- 전화번호·주소·통관번호는 화면에 나오지 않고, 이름은 `김*희`처럼 가려서 보여 줍니다.

## 설치 (처음 한 번, 약 5분)

1. **inm1475@gmail.com** 계정으로 「마진계산 주문처리정리_2026년」 시트를 엽니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 파일 목록에서 `+` → **스크립트**를 눌러 `Config`, `Sheets`, `Checks`, `Code` 파일 4개를 만들고, 이 폴더의 같은 이름 `.gs` 파일 내용을 각각 붙여 넣습니다. 처음부터 있던 `Code.gs` 내용은 지우고 붙여 넣으세요.
4. `+` → **HTML**을 눌러 `Index` 파일을 만들고 `Index.html` 내용을 붙여 넣습니다.
5. 왼쪽 **⚙ 프로젝트 설정**에서 **"appsscript.json" 매니페스트 파일을 편집기에 표시**를 켜고, `appsscript.json` 내용을 붙여 넣습니다.
6. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형은 **웹 앱**을 고릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만**
7. **배포**를 누르고 권한 요청이 뜨면 허용합니다. "확인되지 않은 앱" 경고가 나오면 **고급 → 이동**을 누르세요. 본인이 만든 스크립트라 안전합니다.
8. 나온 **웹 앱 URL**을 휴대폰과 PC에 즐겨찾기 해 두면 끝입니다.

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

## 기준 바꾸기

`Config.gs` 맨 위에서 바꿀 수 있습니다.

- `MISSING_ORDER_DAYS`: 발주 누락으로 볼 일수 (기본 2)
- `NO_TRACKING_DAYS`: 자동취소 의심으로 볼 일수 (기본 7)
- `HOLD_WARN_DAYS` / `HOLD_ALERT_DAYS`: 체크 건 주황 / 빨강 기준 (기본 3 / 5)
- `STATUS_CANCEL`, `STATUS_DONE`, `STATUS_HOLD`: A열 상태값 분류
  - 대시보드 맨 아래 **"시트에 있는 상태값 목록"**을 열면 실제로 쓰이는 상태값과 건수가 나옵니다. 거기서 빠진 값이 보이면 여기에 추가하세요.
- `RECENT_ROWS`: 에코트랜스·발송정보일괄등록 탭은 계속 쌓이므로 맨 아래 몇 행만 검사합니다 (기본 400)
