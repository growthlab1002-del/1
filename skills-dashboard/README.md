# 스킬 워크플로우 보드

와디즈 스킬 팩(스킬 22개 + 작업지침 4개)을 파트별로 나누고, claude.ai에서 단계별로 실행하는 대시보드입니다.
각 단계에서는 Claude가 그 스킬의 `SKILL.md`와 참고 파일을 그대로 따라 일하고, 결과를 다음 단계로 넘깁니다.
이미지는 **매그니픽(나노바나나 2)**, 영상은 **힉스필드**로 같은 화면에서 바로 만듭니다.

- 실행은 보는 사람의 Claude 계정 사용량으로 돌아갑니다. API 키는 필요 없습니다.
- 생성은 claude.ai에 연결된 매그니픽·힉스필드 커넥터로 하고, 각 서비스의 크레딧을 씁니다.

## 파트

| 파트 | 스킬 |
|---|---|
| 영상 기획 | reference-analysis, video-concept, camera-angle |
| 이미지·영상 생성 | contiboard, keyvisual, keyvisual-v2, product-image, image-prompt, image-to-video |
| 이미지 합성 | composite-person, composite-product |
| 제안서 | proposal-deck, storyboard-deck |
| SNS 기획·운영 | sns-concept, content-calendar, shortform-plan, channel-repurpose, video-to-shorts, sns-marketing |
| 세일즈·고객 | quote-builder, cs-reply, outsource-sales |

팩에 새 스킬이 생기면 "기타" 파트에 자동으로 들어갑니다. 분류는 `template.html`의 `PARTS`에서 바꿉니다.

## 워크플로우

| 흐름 | 단계 | 기준 |
|---|---|---|
| 광고 영상 제작 | 레퍼런스 → 컨셉·씬 → 배우 → 제품 → 씬 이미지 → 영상 → 제안서 | 04_작업지침/01 |
| SNS 운영 | 계정 컨셉 → 한 달 편성 → 한 편 기획 → 채널별 배포 | 04_작업지침/02 |
| 긴 영상 재활용 | 숏폼 구간 고르기 → 채널별 배포 | 04_작업지침/02 |
| 수주·고객 응대 | 제안서 → 견적 → 계약 후 소통 | 04_작업지침/03 |
| SNS 마케팅 점검 | 진단·목표 → 성과 분석 → 경쟁 비교 → 월간 리포트 | sns-marketing 단계표 |
| 외주 세일즈 | 접수·수주 판단 → 제안서 → 팔로업 → 견적 → 킥오프 → 계약 후 응대 | outsource-sales 단계표 |

**새 프로젝트 → 직접 만들기**에서 스킬을 골라 순서를 잇고, 그 순서를 내 워크플로우로 저장할 수 있습니다.

## 쓰는 법

1. 흐름을 고르고 브리프(제품·목표·타깃·채널·톤·피할 것)를 적습니다.
2. **이 단계 시작**을 누르면 Claude가 스킬 절차대로 진행합니다.
   - **확인 모드:** 스킬이 묻는 곳(컨셉 고르기, 배우 픽 등)에서 멈춥니다. 답을 적어 이어 갑니다.
   - **자동 모드 / 남은 단계 자동 실행:** 묻지 않고 가정을 표시하며 끝까지 진행합니다. 단가·실적·정책은 지어내지 않고 빈칸으로 둡니다.
3. 오른쪽 **완료 조건**과 **다음 단계로 넘길 것**을 확인하고 **단계 완료**를 누릅니다.
4. 이미지·영상 단계에서는 아래 **생성** 패널에 씬별 프롬프트가 정리됩니다.
   - **이미지 만들기:** 매그니픽 나노바나나 2로 만듭니다. 앞 단계 이미지를 참고 이미지로 붙일 수 있습니다.
   - **영상 만들기:** 힉스필드로 만듭니다. 모델(Kling 3.0 본 작업용, Seedance 2.0 테스트용 등)·길이·비율·품질을 고르면, 만들기 전에 예상 크레딧을 보여 줍니다. 첫 프레임은 같은 씬 번호의 이미지가 자동으로 골라집니다.
   - 결과는 「열기」 링크로 보입니다. 단계를 끝내면 링크가 다음 단계로 넘어갑니다.
5. **내보내기**로 진행표·결과·대화를 .md 파일로 받습니다.

## 안 되는 것

- **결과 미리보기:** claude.ai 페이지 보안 규칙 때문에 생성된 이미지·영상을 페이지 안에 띄울 수 없습니다. 「열기」 링크로 확인합니다.
- **내 사진 업로드:** 내 컴퓨터의 사진은 페이지에서 바로 올릴 수 없습니다. 공개 이미지 주소를 「내 이미지를 링크로 추가」에 넣습니다.
- **파일·스크립트:** 엑셀·PPT 파일 생성과 스크립트 계산(`*.py`)은 하지 않습니다. 같은 내용을 표·마크다운으로 받고, 계산은 Claude가 직접 하고 "스크립트 검산 못 함"으로 표시합니다.
- **영상 파일 분석:** 영상 파일은 열지 못합니다. 자막(SRT)·캡처·설명으로 진행합니다.

## 빌드

```bash
python3 skills-dashboard/build.py ~/Downloads/wadiz-skills-pack.zip
# → skills-dashboard/dist/skills-dashboard.html
```

- 결과 파일에는 구매한 스킬 원문이 들어가므로 `dist/`는 저장소에 올리지 않습니다(`.gitignore`).
- 팩을 업데이트하거나 `price-table.md`·`policy.md` 같은 참고 파일을 채운 뒤에는, 다시 빌드해서 같은 claude.ai 페이지에 다시 발행합니다.
